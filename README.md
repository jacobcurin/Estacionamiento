# Sistema de Estacionamiento

Aplicación de consola desarrollada en C# que calcula el precio de un servicio de estacionamiento según el tiempo ingresado por el usuario.

Tarifas
Hasta 60 minutos: $5.000
Más de 60 y hasta 120 minutos: $15.000
Más de 120 minutos: $40.000
Funcionalidades
Solicita las horas y los minutos adicionales.
Convierte las horas a minutos.
Calcula el tiempo total de permanencia.
Determina automáticamente la tarifa correspondiente.
Valida que los datos ingresados sean números enteros.
Rechaza números negativos.
Valida que los minutos adicionales estén entre 0 y 59.
Repite la solicitud cuando los datos son incorrectos.
